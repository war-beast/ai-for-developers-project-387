# 02: Форма гостя и подтверждение брони с темой разговора

**What to build:** Гость видит в форме бронирования поле «Тема разговора»,
предзаполненное значением по умолчанию, может его изменить и не может ввести
больше 250 символов. После успешной брони тема показана на экране
подтверждения.

**Blocked by:** 01 — тема разговора в контракте, хранении и API.

**Status:** ready-for-agent

- [ ] В форме бронирования есть поле «Тема разговора».
- [ ] Поле предзаполнено значением «Пожаловаться на трудную судьбу».
- [ ] Поле ограничивает ввод 250 символами.
- [ ] Тема отправляется вместе с остальными данными бронирования.
- [ ] Ошибка валидации темы из API показывается рядом с полем.
- [ ] Экран подтверждения показывает «Тема разговора: …».
