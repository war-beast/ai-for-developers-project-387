# 04: Сквозные проверки темы разговора

**What to build:** Smoke-проверка API и браузерные сценарии подтверждают, что
обязательная тема разговора проходит через форму гостя, API и список встреч
владельца, поэтому `mise run check` остаётся зелёным.

**Blocked by:** 02 — форма гостя и подтверждение брони с темой разговора;
03 — тема разговора в списке встреч владельца.

**Status:** ready-for-agent

- [ ] Smoke-проверка создаёт запись с темой разговора и получает `201`.
- [ ] Smoke-проверка проверяет запрос без темы как `400 validation_failed`.
- [ ] E2E-сценарий: гость заполняет тему и видит её в подтверждении.
- [ ] E2E-сценарий: владелец видит тему в списке встреч.
- [ ] `mise run check` завершается успешно.
