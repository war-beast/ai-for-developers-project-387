# 03: Тема разговора в списке встреч владельца

**What to build:** Владелец видит тему разговора рядом с каждой записью в
списке встреч. Для старых записей без темы показывается значение по умолчанию.

**Blocked by:** 01 — тема разговора в контракте, хранении и API.

**Status:** ready-for-agent

- [ ] В `/admin/meetings` рядом с записью отображается
      «Тема разговора: …».
- [ ] Для записи без сохранённой темы отображается значение по умолчанию.
- [ ] Остальные данные записи и пустое состояние списка не изменились.
