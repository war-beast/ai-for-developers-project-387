# 01: Тема разговора в контракте, хранении и API

**What to build:** Гость может отправить обязательную тему разговора при
бронировании, а API возвращает её в созданной записи и в списке предстоящих
встреч. Записи, созданные до появления поля, отдаются со значением по
умолчанию «Пожаловаться на трудную судьбу».

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] В контракте создания записи и в модели записи есть обязательное поле
      «Тема разговора».
- [ ] Запрос без темы или с темой только из пробельных символов возвращает
      `400 validation_failed` с ошибкой по полю `topic`.
- [ ] Тема длиннее 250 символов вместе с пробельными возвращает
      `400 validation_failed`.
- [ ] Тема обрезается от крайних пробельных символов перед сохранением.
- [ ] Созданная запись и список предстоящих встреч содержат тему.
- [ ] Запись без сохранённой темы отдаётся со значением по умолчанию.
